# Mga Tuntunin ng Serbisyo

**Petsa ng Pagpapatupad:** Nobyembre 1, 2025  
**Huling Binago:** Nobyembre 21, 2026  
**Jurisdiction:** Republika ng Pilipinas  

Maligayang pagdating sa Zapwebp. Ang mga Tuntuning ito ng Serbisyo ("Mga Tuntunin") ang namamahala sa iyong pag-access at paggamit sa mga application, serbisyo, command-line interface, AI agent integrations, at open-source packages ng Zapwebp (kabuuan: "Serbisyo").

Sa pamamagitan ng paggamit sa web application, pagpapatakbo ng CLI (`zapwebp`), o paggamit ng `@zapwebp` packages, sumasang-ayon ka sa mga Tuntuning ito.

---

## 1. Pagmamay-ari ng Nilalaman ng User

Pinapanatili mo ang buo at eksklusibong pagmamay-ari sa lahat ng orihinal na imahe at mga file na iyong pinoproseso sa pamamagitan ng Zapwebp.
- **Walang Pag-angkin sa Media**: Walang inaangking karapatan o lisensya ang Zapwebp sa iyong mga converted asset.
- **Katiyakan sa Privacy**: Ang mga na-convert na file ay pag-aari mo lamang. Hindi ito itinatago o muling ginagamit ng Zapwebp.

---

## 2. Lisensyang Open-Source

Ang source code at mga opisyal na package ng Zapwebp ay ipinamamahagi sa ilalim ng **MIT License**. Malaya kang suriin, baguhin, at ipamahagi ang software alinsunod sa mga kondisyon ng lisensyang ito.

---

## 3. Patakaran sa Katanggap-tanggap na Paggamit

Sumasang-ayon ka na hindi gagamitin ang Serbisyo upang:
1. Magsagawa ng denial-of-service (DoS) attacks o magbaha ng mga request sa pampublikong API lampas sa mga itinakdang limitasyon.
2. Lampasan ang mga security boundary o subukang ma-access ang mga pribadong network o filesystem roots.
3. Magpadala ng mga nakakapinsalang script o malware na nakatago sa loob ng mga vector o raster na file.

---

Ipinagkakaloob ang Zapwebp sa batayang "as is" at "as available", nang walang anumang hayag o ipinahiwatig na warranty. Bagama't sinisikap naming panatilihin ang mataas na kalidad at uptime, hindi magagarantiyahan na ang pampublikong web application ay walang patid o palaging magagamit.
