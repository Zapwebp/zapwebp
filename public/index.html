HOW IT WORKS

Built to convert correctly.

Correctness is enforced, not hoped for.

Transparency Preserved

ImageMagick defaults to a black background. Zapwebp enforces transparency. If the alpha channel is lost, the conversion fails.

Runs Locally

Execution happens in your browser. No uploads, no server timeouts, and no exposure to the network.

Multipliers

Generate 1x, 2x, and 3x outputs in one drop. Includes ready-to-use <picture> and srcset HTML.

Clean Mode

Removes EXIF, XMP, and C2PA metadata by default. Output is verified to contain zero metadata chunks before writing.

DEVELOPERS

Terminal CLI & AI Agents

The same conversion engine in your command line and editor. 

# Convert an SVG with @1x/@2x/@3x scales and clean metadata
$ npx zapwebp logo.svg --to webp --scale 1,2,3 --clean

# Batch convert an entire assets folder
$ zapwebp src/assets/*.png --to avif --quality 85

# Undo previous batch
$ zapwebp undo
// Connect to Cursor, Windsurf, or Claude Desktop
{
  "mcpServers": {
    "zapwebp": {
      "command": "npx",
      "args": ["-y", "@zapwebp/mcp"]
    }
  }
}
// vite.config.js
import { defineConfig } from 'vite';
import { zapwebp } from '@zapwebp/plugin-sdk/vite';

export default defineConfig({
  plugins: [zapwebp({ formats: ['webp', 'avif'], quality: 85, clean: true })],
});
# Convert an image using the REST API
curl -X POST https://zapwebp.vercel.app/api/v1/convert \
  -F "svg=@logo.svg" \
  -F "to=webp" \
  -F "quality=85" \
  --output logo.webp
