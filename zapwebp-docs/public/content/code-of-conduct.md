# Code of Conduct

Covers: Community participation pledge, expected standards, unacceptable behaviors, enforcement guidelines, and reporting channels.

Does not cover: Technical code style and API architecture. See [Contributing](/contributing) and [Developers](/developers).

Applies to: All Zapwebp community spaces, repositories, issue trackers, discussions, and pull requests.

## Quick start

```bash
# Review community guidelines online
open https://zapwebp-docs.vercel.app/code-of-conduct
```

Report violations directly to the maintainer via email: [eldrexdelosreyesbula@gmail.com](mailto:eldrexdelosreyesbula@gmail.com).

## What it does

Zapwebp adopts the Contributor Covenant v2.1 to foster an open, welcoming, diverse, and inclusive environment.

### Our Standards

Positive contributions include:
- Demonstrating empathy and kindness toward other community members.
- Respecting differing opinions, viewpoints, and levels of experience.
- Giving and gracefully accepting constructive feedback.
- Accepting responsibility and apologizing to those affected by mistakes.

Unacceptable behaviors include:
- Sexualized language, imagery, or inappropriate attention.
- Trolling, insulting, derogatory comments, and personal or political attacks.
- Public or private harassment.
- Publishing others' private information without explicit permission.

## Enforcement Guidelines

Community leaders are obligated to investigate reports of unacceptable behavior and take corrective action:

| Action Level | Description | Consequence |
|---|---|---|
| **1. Correction** | Private reprimand for minor infraction | Written guidance on community standards |
| **2. Warning** | Warning for repeated or serious violation | Continued monitoring of contributions |
| **3. Temporary Ban** | Suspension from community interaction | Temporary block from repo and discussions |
| **4. Permanent Ban** | Repeated harassment or egregious violation | Permanent ban from all project spaces |
