# Neocities Storage with Zapwebp Starter

Runnable starter template for converting images before upload to a Neocities static site with `@zapwebp/storage`.

## Important Notice

Neocities is a **public static web host**, not a private cloud storage service.
- All files are public by default.
- Free tier has a **1 GB storage limit** and a **10 uploads/minute rate limit**.
- Do not store private, sensitive, or regulated user data on Neocities.

## Prerequisites

1. A Neocities account.
2. Node.js 18+.

## Quick Start

1. Copy environment variables:
   ```bash
   cp .env.example .env
   ```
2. Fill in your Neocities username, password, and site name.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the upload script:
   ```bash
   npm start
   ```
