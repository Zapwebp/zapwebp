# Changelog

All notable changes to `zapwebp-next` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-04

### Added
- Initial stable release of `zapwebp-next`.
- Next.js Webpack integration for automatic asset conversion during static export (`next export` / `output: 'export'`).
- Custom loader helper for `<Image>` component optimizing vector transparency.
- Full App Router and Pages Router compatibility.
