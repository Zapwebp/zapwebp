# Changelog

All notable changes to `@zapwebp/shared` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-11-04

### Added
- Comprehensive MIME type and file extension matrices for SVG, PNG, JPEG, WebP, AVIF, GIF, TIFF.
- Supported format pairs enumerator and transparency capability matrix.
- Structured error code catalogs and localization helpers.
- Canonical URL helpers and origin constants.

## [1.0.0] - 2025-11-01

### Added
- Initial shared constants and type contracts.
