# Changelog

All notable changes to `zapwebp-lens` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-04

### Added
- Initial stable release of `zapwebp-lens`.
- `lens inspect <file>` command printing image dimensions, channels, metadata blocks, and color depth.
- `lens diff <original> <converted>` visual difference and PSNR/SSIM calculation.
- `lens alpha <file>` command verifying presence and coverage of alpha channels.
