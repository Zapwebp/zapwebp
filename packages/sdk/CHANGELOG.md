# Changelog

All notable changes to `@zapwebp/sdk` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.1] - 2026-11-04

### Fixed
- Enforce public access distribution configuration on npm registry.

## [1.1.0] - 2026-11-04

### Added
- Dual execution mode: local offline in-memory execution and remote REST API client mode.
- Multi-target conversion pipelines with transparency verification and optimization tools.
- Webhook signature validation utilities.

## [1.0.0] - 2025-11-01

### Added
- Initial release of official Zapwebp JavaScript/TypeScript SDK.
