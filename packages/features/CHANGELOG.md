# Changelog

All notable changes to `@zapwebp/features` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-11-04

### Added
- Pure state machine reducer for conversion operations.
- Web worker message dispatcher with transferable ArrayBuffer support.
- Bounded concurrency BatchManager.
- MultiplierService for responsive image planning and srcset generation.
- CleanService for metadata analysis and provenance verification.

## [1.0.0] - 2025-11-01

### Added
- Initial vertical slice architecture extract.
