# Changelog

All notable changes to `@zapwebp/ui` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-04

### Added
- Initial stable release of `@zapwebp/ui`.
- High-contrast, WCAG 2.2 AA compliant drag-and-drop zone.
- Reactive conversion cockpit bar with reactive format, scales, quality, clean mode, and lossless controls.
- Interactive split/overlay image preview modal with transparency checkerboard background.
- Responsive result card with single-click download and removal actions.
