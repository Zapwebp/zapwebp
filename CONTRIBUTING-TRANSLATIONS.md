# Contributing Translations

> **Official Documentation Portal:** The internationalization guide and translators directory are published on our core documentation platform at [https://zapwebp-docs.vercel.app/translators](https://zapwebp-docs.vercel.app/translators). Agent specifications are mirrored at [https://zapwebp-docs.vercel.app/content/translators.md](https://zapwebp-docs.vercel.app/content/translators.md).

Thank you for helping localize Zapwebp!

Please review our complete [Translation Guide (TRANSLATIONS.md)](./TRANSLATIONS.md) for full instructions on:
- Supported locales and catalog directory structure
- Immutable key discipline and placeholder preservation rules
- Adding a new locale under `/locales/<locale-code>/`
- Running the CI validation test suite (`node scripts/validate-locales.js` and `pnpm test`)
- Adding your attribution to our [Translators Directory (TRANSLATORS.md)](./TRANSLATORS.md)

Every approved language contributor is credited in release notes and contributor acknowledgments.
